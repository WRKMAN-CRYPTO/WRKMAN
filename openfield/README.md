# OpenField α

A mobile-first prototype for a social network where every person has their own AI and the network optimizes for capability, knowledge, connection, and joy instead of ad engagement.

## What works in this prototype
- User-shaped feed filters
- Local persistent demo state
- Offline-friendly PWA shell
- Draft AI-assist demo logic
- Personal AI network-search demo
- Knowledge gardens
- Portable JSON export
- Hidden vanity counts by design

## Core product thesis
The platform should not own the user, the feed, or the intelligence layer. Identity, posts, follows, gardens, and AI preferences should be portable. AI is the user's tool, not the platform's persuasion engine.

## Next build targets
1. Real identity + signed posts
2. Feed protocol and local-first cache
3. Provider-agnostic personal AI interface
4. Source/provenance trails

6. Trust + anti-spam without global popularity scores
